# Видеоплеер для локальных файлов

## Описание
Простой видеоплеер для воспроизведения видеофайлов с локального устройства.

## Функциональность
- Воспроизведение видеофайлов
- Регулировка громкости
- Отображение информации о файле
- Адаптивный дизайн

## Технологии
- HTML5 Video API
- CSS3 (Flexbox)
- Vanilla JavaScript

## Установка
1. Клонируйте репозиторий
2. Откройте `index.html` в браузере

## Использование
1. Нажмите "Выберите файл"
2. Выберите видеофайл
3. Используйте кнопки управления
